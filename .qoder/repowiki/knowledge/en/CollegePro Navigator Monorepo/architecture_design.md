The repo is a monorepo with three sibling modules: `src/` (TanStack Start + React 19 frontend), `backend/` (FastAPI + Supabase + Gemini services), and `docs/` (product strategy and architecture notes). The frontend and backend communicate over HTTP — the frontend calls `http://localhost:8000` by default (`VITE_API_URL` overrides it) and both share a Supabase database whose schema lives in `backend/supabase_schema.sql` plus additive migrations. Vite drives the dev/build pipeline for the whole repo via `bun run dev` / `bun run build`, while the backend runs independently via `uvicorn main:app`. Nitro is configured in `vite.config.ts` to target Cloudflare Pages/Workers for deployment.

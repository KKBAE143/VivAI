The entry point `main.py` bootstraps a single FastAPI app, installs global middleware (`CatchAllErrorMiddleware` then `CORSMiddleware`), and includes every feature router from the `api/` package. Cross-cutting concerns are centralized in `core/`: settings via Pydantic `get_settings()`, database connection through `database.py`, dependency injection via `deps.py`, structured logging, and error handling. Domain logic is split into `services/` (activity, gamification, readiness, team-project linking) which are consumed by multiple API routers. The `ai/` package provides reusable Gemini-driven services (code-aware viva, sentiment analysis, delivery metrics, report generation) used across `viva`, `presentation`, `live`, and `team_live` endpoints. Data persistence goes through Supabase (schema in `supabase_schema.sql`, migrations under `migrations/`) with Pydantic models in `models/schemas.py` shared between API layers and services. Tests under `tests/` mirror the feature layout and use `conftest.py` for fixtures.

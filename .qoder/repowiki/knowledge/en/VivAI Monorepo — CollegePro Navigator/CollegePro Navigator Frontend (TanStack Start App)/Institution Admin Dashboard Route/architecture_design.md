Single-file route component registered via TanStack Router's `createFileRoute("/admin/")` pattern. The `AdminDashboard` component is the only exported UI; it gates access by reading the profile role from `useAuth` and redirects non-admins to `/`. Data fetching is delegated entirely to hooks in `@/lib/hooks-features` (`useInstitutionDashboard`, `useInstitutionStudents`, `useInstitutionReadinessReport`, `useInstitutionWeakTopics`, `useInstitutionInvite`), keeping this file purely presentational plus local client-side state (pagination page, branch/year filter). Side effects — CSV download and clipboard copy — call the shared `api` client directly rather than going through a hook. Layout chrome (`AppShell`, `PageHeader`, `Card`, `Badge`) and loading/error shells (`CardSkeleton`, `ErrorState`) are imported from `@/components/*`, so this module has no layout or shell of its own and composes the existing app-shell primitives.

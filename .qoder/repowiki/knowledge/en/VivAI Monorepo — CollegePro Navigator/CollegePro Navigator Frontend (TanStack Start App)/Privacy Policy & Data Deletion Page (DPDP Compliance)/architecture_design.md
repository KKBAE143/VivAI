Single-file route component registered via `createFileRoute("/privacy")` from `@tanstack/react-router`, which also defines SEO metadata through the `head` option. The page composes shared UI primitives (`AppShell`, `Card`, `PageHeader`) from `@/components/app-shell` and consumes authentication state through the `useAuth` context from `@/lib/auth-context`. All API calls go through the centralized `api` client from `@/lib/api`. Policy content is declaratively defined as a `POLICY_SECTIONS` array of objects (icon, heading, body), keeping the JSX free of hardcoded text. The delete-flow state machine (`idle | confirming | deleting | done | error`) drives conditional rendering of confirmation, loading, success, and error states without external state libraries.

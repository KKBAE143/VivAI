The module is organized around TanStack Router's file-based routing convention. `src/router.tsx` exports a single factory `getRouter()` that creates the router instance, injects a fresh `QueryClient` into router context, and enables scroll restoration plus zero-stale-time preloading. `src/routeTree.gen.ts` is an auto-generated manifest produced by the TanStack Router codegen — it imports each route's named `Route` export from `src/routes/*.tsx`, wires them under the root via `getParentRoute: () => rootRouteImport`, and exposes typed `FileRoutesByFullPath` / `FileRoutesByTo` / `FileRoutesById` mappings used for type-safe navigation. `src/routes/__root.tsx` defines the root route using `createRootRouteWithContext<{ queryClient: QueryClient }>()`, providing the `<html>` shell (`shellComponent`), a `NotFoundComponent`, an `ErrorComponent` with retry/reset, and wraps all nested routes in `QueryClientProvider` → `ThemeProvider` → `AuthProvider` with an `<Outlet />`. Each sibling file under `src/routes/*.tsx` declares a top-level route via `createFileRoute("/<path>")({ head, component })`, keeping SEO metadata co-located with the page component. The dependency direction is strictly one-way: generated `routeTree.gen.ts` imports route modules; route modules import UI components and libs but never the router factory.

The app is bootstrapped by `src/start.ts`, which creates a TanStack Start instance with server-side error middleware rendering the HTML page from `lib/error-page.ts`. The router in `src/router.tsx` builds a TanStack Router with a shared `QueryClient` injected as router context and imports the generated route tree from `routeTree.gen.ts`. Routes under `routes/` are file-based, each page component composing reusable UI from `components/ui/` (shadcn primitives) and domain-specific components under `components/{live,projects,reports,tasks,code-aware}`. Cross-cutting concerns — authentication (`lib/auth-context.tsx`), React Query setup (`lib/query.ts`), theme (`lib/theme.tsx`), speech synthesis (`lib/speech.ts`), and custom hooks (`hooks/`, `lib/hooks*.ts`) — are provided at the root shell (`__root.tsx`) and consumed throughout via React context and router context.

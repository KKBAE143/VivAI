This module is a flat collection of five standalone documents plus a `repowiki/` knowledge base — no code or build system. The root contains four narrative documents: `problem-statement.md` defines the user pain and product thesis; `platform-overview.html` is a self-contained single-file HTML guide (with embedded CSS Grid layout, CSS custom properties, DM Sans + Instrument Serif fonts from Google Fonts, and vanilla JS) serving as the internal product bible; `QUALITY-UPGRADE.md` is an architectural retrospective documenting six root causes and their fixes across the live-session engine, Kanban, Teams, error middleware, and language support; `pilot-outreach-deck.md` is a 12-slide sales deck with speaker notes targeting Tier-2/3 colleges; `strategy-plan.md` lays out the B2B institutional sales strategy, DPDP compliance roadmap, and Defense Readiness Score framework. The `repowiki/` directory holds structured Markdown knowledge organized by topic (Architecture Overview, API Reference, Backend API, Frontend Application, Real-Time Collaboration, Features & Modules, AI Services, Knowledge Base), with each sub-topic containing its own `.md` file and some sub-folders mirroring the codebase structure. Documents cross-reference each other (e.g., the quality upgrade references files in `backend/`, `api/`, `core/`, and `src/lib/`) but have no internal dependencies on code — they are reference material consumed by engineers, PMs, and sales.

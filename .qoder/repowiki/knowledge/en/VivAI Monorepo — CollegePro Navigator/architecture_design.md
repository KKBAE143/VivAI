Three sibling modules share the workspace root: `src/` (TanStack Start + React 19 frontend), `backend/` (FastAPI + Supabase SDK + Google Gemini services), and `docs/` (product strategy and DPDP compliance notes). The frontend and backend communicate over HTTP — the frontend calls `http://localhost:8000` by default (`VITE_API_URL` overrides it) and both connect to the same Supabase database whose schema lives in `backend/supabase_schema.sql` plus additive migrations. Vite drives the dev/build pipeline for the whole repo via `bun run dev` / `bun run build`, while the backend runs independently via Uvicorn. Nitro is configured in `vite.config.ts` to target Cloudflare Pages/Workers for deployment.

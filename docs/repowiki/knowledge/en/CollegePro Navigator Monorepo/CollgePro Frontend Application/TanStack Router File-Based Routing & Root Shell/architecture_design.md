The module follows TanStack Router's file-based routing convention. `src/router.tsx` is the single factory (`getRouter`) that constructs a router instance with a shared `QueryClient` injected via router context, enabling scroll restoration and zero-stale-time preloading. `src/routeTree.gen.ts` is an auto-generated manifest produced by the TanStack Router codegen — it imports each route's `Route` export from `src/routes/*.tsx`, wires them under the root via `getParentRoute: () => rootRouteImport`, and exposes typed path/to/id mappings. `src/routes/__root.tsx` defines the root route using `createRootRouteWithContext<{ queryClient: QueryClient }>()`, providing the HTML shell, `<HeadContent>`/`<Scripts>`, a 404 `NotFoundComponent`, an `ErrorComponent` with retry/reset, and wraps all nested routes in `QueryClientProvider` → `ThemeProvider` → `AuthProvider` with an `<Outlet />`. Each sibling file under `src/routes/*.tsx` declares a top-level route via `createFileRoute("/<path>")({ head, component })`, keeping route metadata (SEO meta tags) co-located with the page component. The dependency direction is strictly one-way: generated `routeTree.gen.ts` imports route modules; route modules import UI components and libs but never the router factory.

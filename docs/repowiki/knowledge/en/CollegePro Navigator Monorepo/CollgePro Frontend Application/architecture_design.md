The app is bootstrapped by `start.ts`, which creates a TanStack Start instance with a server-side error middleware that renders the HTML error page from `lib/error-page.ts`. The router is constructed in `router.tsx` via `createRouter`, injecting a `QueryClient` into the router context and importing the generated route tree from `routeTree.gen.ts`. Routes live under `routes/` (file-based), each page component composes reusable UI from `components/ui/` (shadcn-style primitives) and domain components under `components/{live,projects,reports,tasks,code-aware}`. Cross-cutting concerns — authentication (`lib/auth-context.tsx`), React Query setup (`lib/query.ts`), theme (`lib/theme.tsx`), speech synthesis (`lib/speech.ts`), and custom hooks (`hooks/`, `lib/hooks*.ts`) — are consumed by both shell and route pages through React context and the router context.
